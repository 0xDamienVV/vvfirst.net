# Relation de Pythagore
Soit $\alpha \in \mathbb{R}$.
> [!property] Propriété
> $\cos^2\alpha + \sin^2\alpha = 1$

### Exemple
- Si $\cos x = \dfrac{4}{5}$ avec $x$ dans le quadrant IV, alors $\sin x = -\dfrac{3}{5}$ car $\sin^2 x = 1 - \dfrac{16}{25}$ et $\sin x < 0$ (voir [[signe]]).

# Relations avec la tangente et la cotangente
Soit $\alpha$ dans le domaine de définition de la [[tangente-et-cotangente|tangente et cotangente]].
> [!property] Propriété
> $1 + \tan^2\alpha = \dfrac{1}{\cos^2\alpha}$  
> $1 + \cot^2\alpha = \dfrac{1}{\sin^2\alpha}$  
> $\tan\alpha \cdot \cot\alpha = 1$

### Exemples
- Si $\tan x = -\dfrac{1}{2}$ avec $x$ dans le quadrant II : $\cos^2 x = \dfrac{1}{1 + 1/4} = \dfrac{4}{5}$, donc $\cos x = -\dfrac{2}{\sqrt{5}}$ et $\sin x = \dfrac{1}{\sqrt{5}}$ car $\cos x < 0$ et $\sin x = \tan x \cos x$.
- $\sin x = \dfrac{\sqrt{11}}{6}$ avec $x$ dans le quadrant II donne $\cos x = -\dfrac{5}{6}$ et $\tan x = -\dfrac{\sqrt{11}}{5}$ car $\cos^2 x = 1 - \dfrac{11}{36}$.
- $\cot x = -\dfrac{2\sqrt{10}}{7}$ est incompatible avec $x \in \left[11\pi, \dfrac{23\pi}{2}\right]$ car $x - 10\pi \in \left[\pi, \dfrac{3\pi}{2}\right]$ est dans le quadrant III où $\cot x \geq 0$.
