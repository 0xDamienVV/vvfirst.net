Soient $A$ et $B$ deux expressions en $x$ et $k \in \mathbb{Z}$.

# Égalité de sinus
> [!property] Propriété
> $\sin A = \sin B \iff A = B + 2k\pi \ \text{ou}\ A = \pi - B + 2k\pi$

### Exemple
- $\sin 2x = \sin\left(x + \dfrac{\pi}{3}\right)$ donne $x = \dfrac{\pi}{3} + 2k\pi$ ou $3x = \dfrac{2\pi}{3} + 2k\pi$, soit $x = \dfrac{2\pi}{9} + \dfrac{2k\pi}{3}$ car on applique les deux cas.

# Égalité de cosinus
> [!property] Propriété
> $\cos A = \cos B \iff A = B + 2k\pi \ \text{ou}\ A = -B + 2k\pi$

### Exemple
- $\cos 2x = \cos\dfrac{x}{3}$ donne $\dfrac{5x}{3} = 2k\pi$ ou $\dfrac{7x}{3} = 2k\pi$, soit $x = \dfrac{6k\pi}{5}$ ou $x = \dfrac{6k\pi}{7}$ car on applique les deux cas.

# Égalité de tangentes
> [!property] Propriété
> $\tan A = \tan B \iff A = B + k\pi$

### Exemple
- $\tan\dfrac{x}{3} = \cot\left(x - \dfrac{\pi}{6}\right) = \tan\left(\dfrac{2\pi}{3} - x\right)$ donne $\dfrac{4x}{3} = \dfrac{2\pi}{3} + k\pi$, soit $x = \dfrac{\pi}{2} + \dfrac{3k\pi}{4}$ car $\cot u = \tan\left(\dfrac{\pi}{2} - u\right)$ (voir [[angles-associes|angles associés]]).

# Sinus égal cosinus
> [!property] Propriété
> $\cos A = \sin B \iff \cos A = \cos\left(\dfrac{\pi}{2} - B\right)$ (voir [[angles-associes|angle complémentaire]])

### Exemples
- $\cos 2x = \sin 3x$ donne $x = \dfrac{\pi}{10} + \dfrac{2k\pi}{5}$ ou $x = \dfrac{\pi}{2} + 2k\pi$ car on écrit $\sin 3x = \cos\left(\dfrac{\pi}{2} - 3x\right)$.
- $\sin 3x = \cos x$ donne $x = \dfrac{\pi}{8} + \dfrac{k\pi}{2}$ ou $x = \dfrac{\pi}{4} + k\pi$ car $\cos x = \sin\left(\dfrac{\pi}{2} - x\right)$.
