Soient $\alpha \in \mathbb{R}$ un angle tel que $\cos\alpha$, $\sin\alpha$, $\tan\alpha$ soient donnés et $k \in \mathbb{Z}$.

# Cosinus
> [!property] Propriété
> $\cos x = \cos\alpha \iff x = \alpha + 2k\pi \ \text{ou}\ x = -\alpha + 2k\pi$

### Exemple
- $\cos x = \dfrac{1}{2}$ pour $x \in [15\pi, 16\pi]$ a pour solution $\dfrac{47\pi}{3}$ car les solutions sont $\pm\dfrac{\pi}{3} + 2k\pi$ et seule $16\pi - \dfrac{\pi}{3}$ est dans l'intervalle (voir [[familles-d-angles|familles d'angles]]).

# Sinus
> [!property] Propriété
> $\sin x = \sin\alpha \iff x = \alpha + 2k\pi \ \text{ou}\ x = \pi - \alpha + 2k\pi$

### Exemple
- $\sin x = -\dfrac{1}{2}$ pour $x \in [15\pi, 16\pi]$ a pour solutions $\dfrac{91\pi}{6}$ et $\dfrac{95\pi}{6}$ car les solutions sont $-\dfrac{\pi}{6} + 2k\pi$ et $\dfrac{7\pi}{6} + 2k\pi$.

# Tangente et cotangente
> [!property] Propriété
> $\tan x = \tan\alpha \iff x = \alpha + k\pi$  
> $\cot x = \cot\alpha \iff x = \alpha + k\pi$

### Exemples
- $\tan x = -1$ pour $x \in [-4\pi, -3\pi]$ a pour solution $-\dfrac{13\pi}{4}$ car les solutions sont $-\dfrac{\pi}{4} + k\pi$.
- $\cot x = \sqrt{3}$ pour $x \in [-\pi, 0]$ a pour solution $-\dfrac{5\pi}{6}$ car les solutions sont $\dfrac{\pi}{6} + k\pi$.

# Argument composé
> [!property] Propriété
> Pour $\sin(ax + b) = c$, on résout d'abord en $u = ax + b$, puis on revient à $x = \dfrac{u - b}{a}$ en adaptant l'intervalle.

### Exemple
- $\sin\left(4x + \dfrac{\pi}{3}\right) = -\dfrac{\sqrt{3}}{2}$ sur $[0, \pi]$ : $4x + \dfrac{\pi}{3} = -\dfrac{\pi}{3} + 2k\pi$ ou $\dfrac{4\pi}{3} + 2k\pi$, d'où $x \in \left\{\dfrac{\pi}{4}, \dfrac{\pi}{3}, \dfrac{3\pi}{4}, \dfrac{5\pi}{6}\right\}$ car on garde les $k$ tels que $x \in [0, \pi]$.
